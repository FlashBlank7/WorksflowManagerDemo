# guanjia 和它的近邻们

> 范本致敬 gptme 的 alternatives 页：替你回答"这和 X 有什么区别"，省掉重复 issue。

## 一句话定位

**guanjia：终端里说人话，远端工厂替你造出能跑、有定时、可监控的工作流。**
交付物是持续运行的工作流，不是一段代码、不是一次执行。

## 对话式终端智能体

| 工具 | 它的取向 | 和 guanjia 的分野 |
| --- | --- | --- |
| aichat | 全能终端 LLM 工作站（Shell 助手/RAG/Agents） | 它执行完就结束；guanjia 的产出**持续存在**——有版本、有定时、有审计 |
| gptme | 模型无关的终端助手，持久自治智能体 | 同上；且 guanjia 的智能体循环在**服务端**，客户端薄到可审计 |
| open-interpreter | 给 LLM 一个 exec()，操作整台电脑 | guanjia 恰恰**不让**模型直接碰你的电脑——本地零执行，能力全在远端受控运行时 |
| aider / claude-code 类 | 编码智能体，产出代码 | guanjia 面向**业务交付物**（报表/对账/监控），用户可以完全不懂代码 |

## 工作流引擎的 CLI

| 工具 | 它的取向 | 和 guanjia 的分野 |
| --- | --- | --- |
| n8n CLI | import/export/execute 运维面 | n8n 的 AI 建流程在网页编辑器；guanjia 的**生成与管理都在对话里** |
| windmill (wmill) | 脚本/flow 当代码同步部署 | wmill 面向工程师的 CI；guanjia 面向"说需求的人" |
| temporal CLI | 工作流开发者的运维终端 | temporal 编排你写的代码；guanjia **替你把工作流造出来** |

## 凭什么可信（不是又一个套壳）

- **生成不是文本生成**：远端莉莉丝在受控 harness 里增量搭建——每个节点过 schema 校验、
  每次验收测试锚定真实数字、失败诚实报告（"空结果诚实"是家法）；
- **智能体不自证**：工具全在服务端执行并入审计台账，答案里的数字都能溯源到账本；
- **本地零信任负担**：客户端纯标准库零依赖、不跑模型、不存业务数据——`uvx guanjia` 免装可验。
