# guanjia 独立产品路线图（2026-08-28 更新）

## 产品定义（不变的锚）

本地薄壳 + 自托管远端；三支柱：**工作流生成**（说人话→活的工作流）、
**统筹管理**（今日/定时/失败一眼清）、**CLI 对话管家**（招牌）。
Web 与 CLI 是同一能力的两张脸，能力一律服务端执行、可审计。
