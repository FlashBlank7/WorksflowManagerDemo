# guanjia 独立产品路线图（2026-08-27 重新规划）

## 产品定义（不变的锚）

本地薄壳 + 自托管远端；三支柱：**工作流生成**（说人话→活的工作流）、
**统筹管理**（今日/定时/失败一眼清）、**CLI 对话管家**（招牌）。
Web 与 CLI 是同一能力的两张脸，能力一律服务端执行、可审计。

## v0.2 —— "核心功能完成"的定义（当前循环的目标）

按用户价值排序，每项都是一个可交付切片：

1. **重构：前端资产化**（本轮）——内嵌 PAGE 巨串拆成 guanjia/web/ 下的
   html/css/js 真文件（importlib.resources 打包内加载），后续前端迭代提速；
2. **Web 对话流式** —— 与 CLI 对齐（SSE 经本地壳透传），消灭静默等待；
3. **Web 生成跟踪 + 提问应答** —— 构建进度、莉莉丝提问直接在对话里答（对齐 CLI）；
4. **会话持久化** —— 对话历史本地落盘（~/.guanjia/sessions/），刷新/重启不丢；
5. **对话 markdown 渲染** —— 管家回答的表格/加粗/列表正常显示；
6. **前端体验 pass** —— 空态、滚动、窄屏、键盘焦点、错误呈现的一轮统一打磨。

## v0.3 —— 走出去
